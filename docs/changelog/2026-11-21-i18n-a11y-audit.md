# 2026-11-21 · 任务 A+B：i18n 完整性审计 + 新组件无障碍审计

## A. i18n 完整性审计

### 审计方法

对 `src/utils/locale.ts` 的 `zh` / `en` 字典做静态扫描，并把 `src/components/**/*.vue`
（20 个组件）+ `src/App.vue` 里实际出现的 `t('…')` / `tMap('…','…')` 键集合与字典键
集合求差。为区分「动态前缀」与「真静态键」，扫描时：

- 去掉 `//` / `/* */` 注释（注释里的示例 `t('shortcuts.items.xxx')` 不算真实使用）；
- `t('foo.' + x)` 形式归入动态前缀命名空间，按「前缀在字典中至少有一个键」校验；
- `tMap('shortcuts.items', subKey)` 按嵌套 Record 的 prefix→subKey 校验（不能用扁平
  `t()` 规则）。

### 结论

**全部完整，无缺失键**。静态扫描最初报出的 12 个「缺失键」全部是动态前缀
（`shapes.type.` / `crossRefs.switch.` / `story.headerParts.` 等）或注释；其对应命名空间
在两本字典中均有完整取值（如 `shapes.type.rectangle/ellipse/…`）。

### 测试加固（原测试覆盖不足）

原 `tests/localeIntegrity.test.ts` 只校验 zh/en **键位/参数一致性**，无法发现「某个键
两本字典都缺」或「新组件用了未定义键」——前述差集正属此类盲区。扩展为 6 项：

1. 定位两本字典（原有）
2. zh/en 键集合一致（原有）
3. 插值参数一致（原有）
4. **组件静态 `t()` 键在两本字典都存在**（新增）
5. **组件动态 `t('prefix.' + x)` 前缀是有效命名空间**（新增）
6. **组件 `tMap()` 嵌套 prefix/subKey 两本字典都能解析**（新增）

新增 3 项均带防退化断言：`componentSources.length >= 20`、静态键数 `>100`、动态前缀数
`>0`、tMap 使用数 `>0`，确保扫描器退化成空集时不会「永真」。

## B. 新组件无障碍审计

对 `CollapsiblePanel.vue` / `PreviewToolbar.vue` / `DocSearchBar.vue` /
`OutlineSidebar.vue` 逐项审查 ARIA 与键盘契约。

| 面 | 结论 |
|---|---|
| 折叠按钮 `aria-expanded`/`aria-controls`、region `aria-labelledby` | 基本正确；发现 `aria-controls` 指向 `v-if` 卸载后不存在元素的小问题（已修）。 |
| 工具栏可访问名 / 禁用态 / `aria-pressed` | 正确：全部按钮有 `aria-label`，缩放/翻页/大纲按状态禁用，隐藏文字与主题用 `aria-pressed`。仅 `aria-controls` 悬空问题（已修）。 |
| 搜索输入 / 结果 `aria-live` | 状态容器 `role=status` + `aria-live=polite`，输入 `aria-describedby` 指向它，正确。 |
| 大纲项可聚焦性 / 跳转 | `role=button` + `tabindex=0` + Enter/Space 转发 + `:focus-visible` 样式，正确。 |

### 发现并修复的真实问题（负控先行）

1. **`DocSearchBar` 选项复选框键盘不可达（真 bug）**：`.search-option input` 原用
   `display:none`，使「大小写敏感 / 全词匹配」复选框退出 Tab 序列与无障碍树，键盘用户
   无法切换这两个搜索选项。改为视觉隐藏（`position:absolute` + 1×1 + `clip:rect(...)`）
   保留可聚焦性，并新增 `.search-option:has(input:focus-visible)` 焦点环。
2. **悬空 `aria-controls`（轻微 ARIA 错误）**：`CollapsiblePanel` 折叠时 region 被
   `v-if` 卸载，但按钮仍保留 `aria-controls` 指向该 id；`PreviewToolbar` 的
   search/outline/shortcuts 切换按钮同理（被控面板由父组件 `v-if`）。改为仅在展开态
   绑定 `aria-controls`（`cond ? id : undefined`）。
