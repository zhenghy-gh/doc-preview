# Round 121 优化记录

日期：2026-10-10

## 目标

评估 `createParagraphsWithRealFormats` 中 CHPX 回退格式合并后的 `styles` 清除路径，尝试避免对象展开与解构 rest 产生的临时对象。

## 候选与等价性

真实 CPU profile（1132 samples）显示 `createParagraphsWithRealFormats` 自耗 11.75%，其中格式合并调用行约 2.47%、`{ ...newPara.charFormat, ...merged }`/解构清除路径约 1.41%。候选把该路径改为两轮键复制，过滤 `styles`，只在隔离 bundle 和主解析器调用路径中测量。

隔离真实输入收集到 32,690 次合并调用；候选与旧实现及 3 个补充边界样例逐项等价。2–3 个故意错误负控（参数反序、保留 `styles`、删除 `fontName`）均被护栏捕获；一个慢但等价的三次旧实现对照也通过等价性检查。

## 验证

- 27 份真实样本完整 `parseWithFormat()` dump：逐字节一致。
- 隔离合并循环 4 组：候选 55.542–69.252 ms，旧版 84.811–87.949 ms；仅用于定位方向，不作为最终采纳依据。
- 主调用路径交错 4×NEW/4×OLD、每进程 40 轮：NEW/OLD 中位数分别为 116.827/118.002、116.223/107.326、110.804/107.073、108.978/108.345 ms；NEW 仅 2/4 组胜出，整体无稳定收益且两组退化。
- 全量测试：76 个测试文件、1448 项通过。
- `vue-tsc --noEmit`、`npm run lint`、`npm run build`、`npm run build:lib`：均通过。
- 包体保持：应用主 JS gzip 109.91 kB；库入口 gzip 94.95 kB；UMD gzip 83.11 kB。
- `bench-diff 121`：27/27 解析成功；median 0.950243、p25 0.915450、p10 0.896816、min 0.811547；与 cycle-120 逐字段一致（仅 cycle/timestamp 除外）。

## 结论

候选在主解析器端到端数据上没有稳定收益，按硬纪律否决并撤回。未升号、未提交生产代码、未发布双包；轮次计入状态，版本保持 `0.7.56`。

## 风险与下一方向

生产代码无变化，无新增兼容性风险。下一轮重新剖析真实热点，优先寻找能在主调用路径交错基准中稳定获益的低分配候选；避免重复尝试对象合并的等价改写。
